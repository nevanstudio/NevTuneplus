# 🎵 NevTune+ — First Public Release

Welcome to the very first public release of NevTune+!
This is where it all begins — a powerful, modern music player built for Android, Android TV, and Wear OS.

---

## What's Included

### 🎧 Phone
- Local music library with full playback controls
- Lyrics support (LRC, synced & unsynced)
- Equalizer with presets
- Last.fm scrobbling
- Discord Rich Presence
- Sleep timer with fade out
- Backup & restore

### 📺 Android TV
- Full TV-optimised interface
- Browse and play your local library on the big screen
- Remote playback control

### ⌚ Wear OS
- Playback controls on your wrist
- Now Playing screen
- Skip, pause, seek from your watch

### 🎉 Listen Together
- Create a party and listen in sync with friends
- Real-time playback sync via the Listen Together server
- Host controls — manage the queue, kick listeners

---

## Supported Audio Formats

FLAC · MP3 · AAC · OGG · OPUS · WAV · AIFF · DSD · and more
